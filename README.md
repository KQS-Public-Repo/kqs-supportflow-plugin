# KQS SupportFlow plugin for Claude

Remote support for your kiosks, workstations and servers, from Claude. This repository is the Claude plugin marketplace
for **KQS SupportFlow** by [Koquelani Systems](https://www.koquelani.com/services). It contains only the plugin: the
SupportFlow Client itself is installed separately with `KQS_SupportFlow_setup.exe`.

## Quick start

1. Install the **SupportFlow Client 1.5.18.1 or later** and sign in: https://www.koquelani.com/services/clientdownload
2. Install the plugin:

   ```
   /plugin marketplace add KQS-Public-Repo/kqs-supportflow-plugin
   /plugin install kqs-supportflow@koquelani-supportflow
   ```

3. Restart Claude.

Full details: [plugins/kqs-supportflow/README.md](plugins/kqs-supportflow/README.md)
